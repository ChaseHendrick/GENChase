# GENChase

Generative art from real scientific simulations. One HTML file, thirty-five techniques, seeded and print-ready.

Open [`studio.html`](studio.html) in a browser, or serve this folder:

```
python3 -m http.server 8080
```

Then visit `http://localhost:8080/studio.html`.

## What it is

Each tab is a pattern-forming system — reaction-diffusion, slime mold, Lenia, fluids, Cahn–Hilliard, Swift–Hohenberg, Lifshitz–Petrich 12-fold quasicrystals, Gravner–Griffeath snowflakes, Penrose and hat monotiles, Helmholtz scars, and the rest — implemented from its governing equations. A seed plus parameters reproduces a plate exactly, at any size.

The URL hash is the recipe. Export is museum-print resolution, with an optional colophon (technique, equation, seed, parameters). Images you generate are yours; sell the prints.
