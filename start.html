Your first print, in three steps

  1. Find something you like

    Choose a pattern or a preset. Generate changes its seed; Surprise also changes the settings and palette. Undo takes you back.

  2. Make it yours

    Adjust colors and controls. Use Pause to hold a moving pattern. Save keeps a recipe in this browser’s gallery; Link copies its settings to share.

  3. Take it with you

    Choose a print size and pixel density, then Export PNG. Start at 8 inches and 300 ppi. The export panel also offers other formats where supported.

Save the image as well as the recipe. Clearing browser storage removes its local gallery. Bigger print dimensions add pixels; a simulation’s own grid controls its numerical detail.

Run scientific checks locally

Use the source download or clone the repository. With Node.js installed, open a terminal in that folder:

npm run setup:checks
npm run validator

Open the local address printed in the terminal. Choose Check simulations for existing tests or Run experiments for new data. Start with a small selection.

For uploads, install GitHub CLI and run gh auth login. Review files under Share results, or opt in to automatic sharing for a run. Results stay local until you choose to share.

Quick developer checks
git clone https://github.com/ChaseHendrick/GENChase.git
cd GENChase
npm test

The fast checks need Node.js and no dependency install. Scientific changes also need the relevant numerical and print checks. Use node tools/verify.js --list --print <module-id> to see the plan.

Published scientific models inspire the art. Evidence and limitations are visible in each technique’s report and the validation inventory.

Keep a studio on your computer

Download the offline ZIP, extract the folder, and open START-HERE.html. Open the studio from that page whenever you like. No server, Node.js, or Python is needed to make art from this bundle.

Use a current browser. Some simulations need WebGL2 and capable graphics hardware. Clipboard and local storage behavior can differ when opened from a file. The source version’s local launcher provides an HTTP alternative.
