central-vortex: two concentric regular n-gons plus a central vortex (DK 2014 Sect. 3, Gamma0 != 0)
Working notes, 2026-09-24. Scratch only; nothing here is in the repository.

SETUP (DK conventions, read from page images p05-p06)
  Gamma1 = 1 on the n-gon of radius 1 (b1 = 1); Gamma2 = -1/X on the n-gon of radius r = sqrt(X), rotated by phi2;
  Gamma0 = gamma at the origin; b2 = e^{i a}, a = n phi2. Collapse branch: Gamma1 + Gamma2 r^2 = 0 (V = 0).
  (37): ((n-1) + 2 gamma) X^2 - 2 (n + gamma) X + (n-1) = 0.   (36): Omega = (A v + B)/(2 X^2 (v - 1)), v = r^n e^{i a},
  A = 2(n+gamma)X - (n-1), B = (n-1) - 2 gamma X.   Omega = 2 pi i conj(kappa), P = |Re Omega|/(2|Im Omega|).

RESULTS (all proved in derive.py by exact SymPy identities; numbers certified in certify.py by Biot-Savart)
 (a) Admissible r: quarter-discriminant of (37) is (gamma+1)^2 + 2(n-1) > 0, so real roots for every real gamma;
     r = 1 is never a root ((37) at X = 1 equals -2). Two positive roots when gamma > -(n-1)/2, one (in (0,1)) when
     gamma <= -(n-1)/2 (at gamma = -(n-1)/2: X = (n-1)/(n+1)). (37) is linear in gamma:
        gamma(X) = 1/(X-1) - (n-1)(X-1)/(2X),  dgamma/dX < 0.
     Symmetry (X, gamma) -> (1/X, -X gamma) = ring interchange + time reversal, same P. So the whole family is
     parametrized by u = ln r in R \ {0} and a; with u = ln r:
        gamma = e^{-u} [n - (n-1) cosh 2u] / (2 sinh u)
     (symmetric normalization Gamma1 = e^u, Gamma2 = -e^{-u}: Gamma0 = 1/(2 sinh u) - (n-1) sinh u).
     Collapse: A + B = 2nX for every gamma, so Im Omega = -n Gamma1 r^{n-2} sin a / (R1^2 |r^n b2 - 1|^2).
        Collapse iff Gamma1 sin a > 0 (with Gamma1 > 0: 0 < a < pi mod 2 pi), for every gamma and both roots.
     P keeps the form of eq. Pring:
        P = (K - B cos a) / (C sin a),  0 < a < pi,  C = 2n (unchanged),
        B = coth|u| = (r^2+1)/|r^2-1|   [= n + 2 gamma - (n-1)/r^2 on (37), up to sign]
        K = n sinh(n|u|) + coth|u| cosh(n|u|) = [(n+1) cosh((n+1)u) - (n-1) cosh((n-1)u)] / (2 sinh|u|)
          = |(2(n+gamma) r^2 - (n-1)) r^n - ((n-1) - 2 gamma r^2) r^{-n}| / (2 r^2)
     K - B cos a = n sinh(nu) + coth u (cosh nu - cos a) > 0: P never vanishes. gamma = 0: K = K_n, B = sqrt(2n-1).
 (b) Lemma 1: P >= F(n, gamma) := sqrt(K^2 - B^2)/(2n), equality iff cos a = B/K
        = 2 cosh u / [(n+1) cosh((n+1)u) - (n-1) cosh((n-1)u)].
     D := K^2 - B^2 = sinh^2(nu) (n^2 + coth^2 u) + n coth u sinh(2nu)
                    = n^2 sinh^2(nu) + [cosh u sinh(nu)/sinh u]^2 + n cosh u sinh(2nu)/sinh u.
 (c) Each term of D is strictly increasing in |u| (sinh(nu)/sinh u and sinh(2nu)/sinh u are sums of cosh(ju)), so
     F is strictly increasing in |ln r|: no interior minimum. r>1 branch (gamma > -(n-1)/2): F decreases in gamma from
     +oo (gamma -> -(n-1)/2+, r -> oo) through F_n (gamma = 0) to sqrt(3)/2 (gamma -> +oo, r -> 1+).
     r<1 branch (all gamma): F increases in gamma from sqrt(3)/2 (gamma -> -oo, r -> 1-) through F_n to +oo (r -> 0).
     D = 3n^2 + (4n^2(2n^2+1)/3) u^2 + O(u^4), so inf = sqrt(3)/2 for every n (not attained), limit as n grows sqrt(3)/2.
        P_min = sqrt(3)/2 + sqrt(3)(2n^2+1)/9 u^2 + O(u^4) ~ sqrt(3)/2 + sqrt(3)(2n^2+1)/(36 gamma^2)
     Minimizer degenerates: cos a* = 1 - (3n^2/2) u^2, a* ~ sqrt(3) n u -> 0 (the polygons close up pairwise).
     P cannot approach 0 (P >= sqrt(3)/2 > 0).
     Per-n exact certificate n = 2..8: D(cosh u = 1 + t) has constant 3n^2 and all other coefficients positive.
 (d) A central vortex lowers the ring minimum from F_n (1.677 at n=2 ... 3.046 at n=8) arbitrarily close to sqrt(3)/2
     but never below: this family never reaches 0.7979 (four vortices) or 0.8054 (DK seven vortices).
     Interpretation (heuristic, not a claimed theorem): as u -> 0 each Gamma1/Gamma2 pair with the central vortex is
     a three-vortex system (Gamma0^(3), e^u, -e^{-u}) with Gamma0^(3) = 1/(2 sinh u) (three-vortex condition
     1/G0 + 1/G1 + 1/G2 = 0 holds exactly), i.e. circulations (1, mu, -mu/(1+mu)) with mu = r^2 - 1 -> 0; the ring
     value differs by -(n-1) sinh u (exact, derive.py 3e), a relative O(u^2) correction from the other pairs.
     sqrt(3)/2 is the mu -> 0 end of the three-vortex bound.

SCRIPTS AND OUTPUT (this folder)
  derive.py  -> derive.out   50/50 exact SymPy checks (symbolic n where possible, n = 2..8 otherwise).
  certify.py -> certify.out  12/12: 1836 configurations, all 2n+1 vortices, 50 digits: self-similar spread <= 2.1e-48,
             centre at rest <= 3.1e-47, DK (36) = 2 pi i conj(kappa) to 1.1e-48, orientation, P(a) to 9.5e-43 (cancellation
             near r = 1); minima found on the BS P itself (grid + golden section + Newton on dP/da) equal
             sqrt(K^2-B^2)/(2n) to 4.7e-47 and a* to 2.9e-37; gamma = 0 gives F_n; symmetric pairs equal; monotone
             branches; gamma = +-1e6 at 80 digits: (P_min - sqrt3/2) gamma^2 = sqrt(3)(2n^2+1)/36 to 1e-5 relative.
  dyn.py     -> dyn.out      double-precision DOP853 integration of all 2n+1 vortices from the minimizer to
             lambda^2 = 1e-4: winding slope and t_c agree to 1e-11..1e-13 where the orbit stays self-similar.
             Exceptions, recorded: n = 5, gamma = 1, r < 1 drifts 3.5e-6 (slope 4.6e-8 off); n = 2, gamma = 10, r < 1
             (r^2 = 0.043, P = 8.9) leaves the self-similar orbit (drift 0.67): round-off amplified by an instability,
             not a failure of the formula (the static 50-digit check is exact). Stability was not analyzed.
