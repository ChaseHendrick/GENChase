# Complete bounded GL field and print reviews

Reviewed 2026-09-22. The acceptance domain is the enumerated recipe list in each result artifact, not the whole parameter interface. The equation conventions and earlier numerical repairs are documented in [GL-CORRECTIONS.md](GL-CORRECTIONS.md). These reviews establish finite lattice calculations and their prints. They do not establish experimental agreement, continuum convergence, magnetic screening, critical fields, calibrated vortex counts, arbitrary chaotic trajectories or long-time statistics.

## Fixed-field vortex

Run `node tools/vortex-field-review.js --write`. Evidence: `validation/results/vortex-field-review.json`.

The equation is `d psi/dt = kappa^-2 (grad-i A)^2 psi + (1-|psi|^2) psi`, with `A=(-0.08 B y,0)`, unit grid spacing, fixed external field and zero order parameter at the edges. The production solver is exact local saturation followed by an explicit unit-modulus-link diffusion step. Increasing grid dimensions enlarges the physical domain; it is not mesh refinement. The independent reference evaluates the local flow and complex neighbor rotations separately, using all four neighbor links rather than the production factored stencil. Both start from the actual deterministic seeded initial array, whose digest is recorded. RNG distribution accuracy is outside this review.

Four full recipes are checked: grid 96, square, B=0.4, kappa=0.5, 30 macrosteps, intensity; grid 96, 4:5, B=3.2, kappa=4, 30 macrosteps, log with exposure 0.8; grid 128, 5:4, B=1.4, kappa=1.6, 90 macrosteps, intensity; and grid 96, 16:9, B=2.6, kappa=2.2, 120 macrosteps, log with exposure 1.2. Seeds, actual grid dimensions and all recipe settings are recorded. Macrostep time is 0.12. Every complex field coordinate must agree within 1e-11, Float32 density within 1e-7, edges must stay zero and amplitude must remain at most one within 1e-12. All checks passed.

The existing kernel audit is executed as part of the review: an independent 18-by-18 complex-link stencil, an intentionally reversed flux, boundedness through 80 updates at kappa=0.5 to 4, and timestep halving of a small-amplitude Dirichlet eigenmode at physical time 0.2. The eigenmode shows first-order convergence. This is a finite-time, linearized lattice benchmark, not a continuum or nonlinear equilibrium result.

For every pixel of the actual 8-inch, 300-ppi engine PNG, a separate calculation maps independently computed density through the documented normalization, optional logarithm, exposure and linear-light palette. Nearest-neighbor magnification uses the lower cell at an exact boundary, matching Chromium's raster rule. RGBA error must be at most one byte per channel; a one-cell displacement must fail. The longest edge is 2400 pixels. Captions and optional smoothing are off. The entire field and recipe must remain unchanged through export. Binary64 field computation, Float32 density storage and RGBA8 rendering are recorded separately.

The winding-plaquette diagnostic is descriptive and excluded from quantitative validation. Default/preset recipes outside these four, GPU or continuum alternatives, physical printer calibration, captions, smoothing, PDF/TIFF and other browsers are excluded.

## Complex Ginzburg-Landau

Run `node tools/cgl-field-review.js --write`. Evidence: `validation/results/cgl-field-review.json`.

The reviewed equation is `d A/dt = mu A + (1+i alpha) laplacian(A) - (1+i beta)|A|^2 A` on a periodic unit-spaced lattice. Exact local cubic flow precedes explicit complex diffusion. This is first-order Lie splitting with diffusion/phase substeps. The independent binary64 CPU implementation separately constructs the analytic wave, vortex or spiral initial array and sums periodic neighbor differences. Its result is compared with every component of the actual RGBA32F production GPU field, allowing absolute component error below 1e-4. The CPU and GPU use the same declared discretization, so this comparison tests implementation agreement. The separately executed exact semidiscrete Fourier-mode benchmark supplies time-convergence evidence against an analytic solution.

The initial full-field audit failed its unchanged 1e-4 tolerance: maximum component error was 5.7728349e-4 in the wave recipe. A local GPU probe isolated sine/cosine error: at phase 0.005, SwiftShader returned cos=0.9999743104 versus the reference 0.9999875000. Repeated rotations therefore introduced artificial amplitude loss. The maintained shader now uses bounded degree-7/8 sine/cosine polynomials for absolute phase at most 0.25; analytic truncation error is below 1.1e-11 before floating-point rounding. Outside that range it retains the GPU intrinsics. A 101-angle GPU regression requires rotation-component and unit-length errors below 1e-7. This correction changes previous CGL recipes; it is a numerical accuracy repair, not a new equation. The full-field checks keep the original 1e-4 limit.

All four recipes use grid 128, 50 macrosteps of 0.02 (physical time 1), no noise, no grain, stopped animation, unit exposure/gamma/contrast and recorded default palette. The cases are: alpha=2, beta=-0.5, mu=1, wave seed, amplitude view, square; alpha=-2, beta=2, mu=1, vortex seed, real view, 4:5; alpha=0, beta=1.4, mu=0.2, spiral seed, amplitude view, 5:4; alpha=4, beta=-4, mu=1.6, vortex seed, defect-intensity view, 16:9. The final view is only an amplitude-based visualization, not a certified count of defects.

The kernel benchmark checks exact local flow, the exact nonlinear semidiscrete Fourier-mode solution at time 0.2 with steps 0.02/0.01/0.005, the reversed-dispersion failure control, Nyquist stability with and without safe substeps, and 153 substep-parameter combinations. The finest Fourier-mode error must be below 1e-4, refinement ratios above 1.7 and wrong-sign error above 0.01. Nyquist decay establishes stability in that example, not accurate grid-scale dynamics.

Every exported RGB channel is compared with a separate CPU calculation of periodic tensor-product cardinal-cubic interpolation, view mapping, a 256-entry linear-light palette and texture interpolation. Print error must be at most two bytes per channel, allowing GPU interpolation/quantization. Alpha must be fully opaque. A one-cell horizontal displacement must disagree. Field and recipe state must remain unchanged. Exports have a 2400-pixel longest edge, captions and smoothing off, in the recorded SwiftShader RGBA32F environment.

Noise-driven behavior, phase-view discontinuities, ongoing animation, long warmups, chaotic statistics, half-float hardware, other GPUs, general continuum accuracy, phase-diagram claims and experimental equivalence are outside this review. These exclusions remain visible in the inventory.
