# GENChase trailer

**[Watch the trailer (MP4, 45 s, 1920 × 1080)](genchase-trailer.mp4)**

Every moving image in it is a real plate of the studio, computed from its recipe in headless Chromium and recorded
frame by frame; nothing is drawn by hand or generated by a model. The recipes are the studio's own hashes, all with
the seed `trailer`, so each clip reprints: open `#fluid/trailer`, `#dendrite/trailer` and so on in the studio. On
a software renderer the frames come as fast as the renderer allows, so the clips are time-lapses of the runs.

The score is original: an ambient electronic piece at 96 BPM, synthesized from oscillators and noise in
`tools/trailer/music.py`, with no samples. The cuts fall on its bar lines.

## Rebuild

From the repository root, after `node tools/build.js` (the recording uses `dist/studio.html`):

```
pip install imageio-ffmpeg        # a static ffmpeg with libx264 and AAC
O=/tmp/trailer
node tools/trailer/capture.js record $O/clips 40 fluid/trailer dendrite/trailer excitable/trailer physarum/trailer \
  cyclic/trailer schrodinger/trailer vegetation/trailer cgl/trailer aztec/trailer knotlight/trailer \
  fractal/trailer cortex/trailer hodgkin-huxley/trailer attractors/trailer
node tools/trailer/capture.js record $O/montage 14 tilings/trailer apollonian/trailer holomorphic/trailer \
  lozenge/trailer ising/trailer kpz/trailer
python3 tools/trailer/music.py $O/score.wav
python3 tools/trailer/assemble.py $O/clips $O/montage $O/score.wav docs/trailer/genchase-trailer.mp4 docs/trailer/poster.jpg
```

Recording takes about 30 minutes on a software renderer; the score takes seconds and the edit a few minutes. Clips
recorded on other hardware, or by another build, will differ in timing and pixels, as the studio's own reprint notes
say.
